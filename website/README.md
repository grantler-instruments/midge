# Midge marketing site

Vite + React + MUI + Zustand landing page using the Grantler dark theme.

```bash
npm install
npm run dev      # http://localhost:5175/midge/
npm run build    # dist/ for GitHub Pages (base /midge/)
```

Routes: `/` (home), `/privacy` (privacy policy).
Deployed to GitHub Pages at https://grantler-instruments.github.io/midge/.

From the repo root: `npm run website:dev` / `npm run website:build` / `npm run build:pages`.
